# EPR Compliance Copilot design handoff

The repository contains the implementation-ready prompt pack and design tokens
for a Vietnamese, light legal-SaaS interface. The current React implementation
uses these tokens and covers the five required product states.

No Stitch export URL or screenshot is committed yet because no approved export
was supplied. Add the export URL and desktop/mobile screenshots to this folder
when the design review is complete; do not claim that a locally recreated UI is
